B. One-pass form filling
One pass should mean one agent call. The runner should still read and check the page.
That is how it catches a new required question without paying for another model turn. Playwright’s
actions and locators already support waiting for usable controls. Mobilerun’s native replay uses the
same broad idea: check state locally before acting. Playwright action checks · Mobilerun replay

The runner I recommend — design
Use four small parts:

1. Answer book: saved facts, exact choices, source, scope, and resume filename.

2. Site adapter: how this site exposes fields, steps, uploads, and confirmation.

3. Shared checker: whether each required answer is present and committed.

4. Run journal: what was filled, what was submitted, and what proof came back.

This follows existing workflow and adapter patterns. The proposed split is mine. Workflow Use ·
Playwright page-object pattern

The answer book must distinguish missing, false, 0, and an empty string. For example, use
Object.hasOwn(answers, key) to check whether an answer exists. Do not use truthiness to decide
whether a saved “No” or zero is missing. That is a design requirement for preserving the saved
answer faithfully.

Use exact field identity where possible: site, form, question label, question ID, and allowed choices.
A numeric input alone does not tell the runner whether it asks for years, salary, notice days, or
something else. Ashby’s own form schema makes these distinctions explicit through IDs, paths,
types, and required flags. Ashby form definitions

Runner skeleton — design
The adapter functions below are the work to implement. This shows the control flow, including the
crucial submission boundary.




                                                                                                 Page 7
 async function runTask(adapter, answers, task, journal) {
   const prior = await adapter.findSubmission(task);
   if (prior) return { status: 'submitted', proof: prior };

     for (let step = 0; step < task.maxSteps; step++) {
       await adapter.ensureReady();

         const gate = await adapter.findHumanGate();
         if (gate) return { status: 'needs_human', gate };

         // Includes fields revealed by earlier answers.
         await adapter.fillUntilStable(answers);

         const problems = await adapter.auditRequiredFields();
         if (problems.length) {
           return { status: 'blocked', problems };
         }

         await journal.saveStep(await adapter.readCommittedAnswers());

         if (await adapter.isFinalStep()) {
           if (!task.allowSubmit) {
             return { status: 'ready_for_review' };
           }

             await journal.markSubmitAttempted();

             try {
               await adapter.submitOnce();
             } catch {
               // The server may have received the request.
             }

             const proof = await adapter.findSubmission(task);
             return proof
               ? { status: 'submitted', proof }
               : { status: 'submission_unconfirmed' };
         }

         await adapter.advanceAndWaitForNextStep();
     }

     return { status: 'blocked', reason: 'step_limit' };
 }
