# Recipes

One card per task that has worked at least once. Same shape every time. When George says "recipe it," a card gets written or updated here. When a run breaks, the card's "last broke" line gets the date and the reason.

Card shape:

```
# <task name>
Machine: laptop Chrome | phone Chrome | hidden screen | rented browser | fetcher
Last worked: YYYY-MM-DD (how long it took)
Last broke: YYYY-MM-DD (why) — or "never"
Needs from the answer book: <keys>
Steps: numbered, by button name, one line each
Stop on: what makes the run stop and report
Receipt: what proves it worked
Script: path, if one exists
```
